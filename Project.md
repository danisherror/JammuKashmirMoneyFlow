#### SECTION 4 — The "Money Gap" Tracker

This is the most powerful section — where does money **get stuck**?

**Gap Type 1: Allocation → Release Gap**
- Finance Dept allocated ₹100 Cr to PWD but only released ₹60 Cr
- Reason: Revenue shortfall, cash flow issues, political hold

**Gap Type 2: Release → Utilization Gap**
- PWD received ₹60 Cr but only spent ₹35 Cr
- Reason: Tender delays, contractor issues, court stays, land disputes (very common in J&K)

**Gap Type 3: Utilization → Ground Reality Gap**
- PWD "spent" ₹35 Cr but the road is only 40% complete
- Source: CAG audit reports flag this every year for J&K

**Visual:** A funnel chart for each department showing money shrinking at each stage.

## ⏰ Scheduler Design

Using **APScheduler** (runs inside FastAPI):

```
DAILY jobs (runs at 6:00 AM IST):
├── mgnrega_collector      → fresh daily data
├── jjm_collector          → fresh daily data
├── dbt_collector          → fresh daily data
└── tender_collector       → new tenders posted

WEEKLY jobs (runs Sunday 2:00 AM IST):
├── pmay_collector         → weekly portal update
├── pfms_collector         → weekly releases
└── gap_calculator         → recalculate all gaps

MONTHLY jobs (runs 26th of month, 8:00 AM IST):
├── budget_collector       → CGA monthly accounts just published
└── data_cleaner           → archive old snapshots

ANNUAL jobs (checks every month):
└── cag_collector          → new audit reports released
```

**Each job:**
1. Runs collector
2. Writes raw data to DB
3. Triggers processor to clean + calculate gaps
4. Updates `data_sync_log` with status
5. If failure → logs error, sends alert (email/Slack webhook)
